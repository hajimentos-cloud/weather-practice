# iPhone のロック画面に天気を出す（Scriptable 版）

iPhone のロック画面・ホーム画面に、天気ウィジェットを置くためのスクリプトです。
**無料アプリ「Scriptable」** の中で動きます。Apple の開発者登録は要りません。

> ウェブページ（`weather/`）そのものは、iPhone のウィジェットにできません。ウィジェットは、アプリでしか作れない iPhone の仕組みのためです。そこで、Scriptable というアプリに小さなスクリプトを入れて、同じ天気データ（Open-Meteo）をウィジェットに出します。

## 出るもの

| ウィジェット | 内容 |
|---|---|
| ロック画面・丸型 | 天気アイコンと、いまの気温 |
| ロック画面・長方形 | いまの気温と天気、場所、最高・最低気温、降水確率、「傘 15〜18時」などの傘のひとこと |
| ロック画面・1行（時計の上） | 「新宿 20° 快晴 降水0%」 |
| ホーム画面・小／中 | 天気に合わせた背景色で、同じ内容 |

タップすると、天気ページ（`https://hajime-weather.vercel.app`）が開きます。

## 設定のしかた（初めての人向け）

### 1. Scriptable を入れる
App Store で **「Scriptable」** を探して、インストールします（無料）。

> ⚠️ これは第三者が作ったアプリです。App Store の評価や開発者を、ご自身で確認してからインストールしてください。

### 2. スクリプトを Scriptable に入れる
1. パソコンで [`weather-widget.js`](weather-widget.js) を開き、**中身をすべてコピー**します（全選択 → コピー）。
2. iPhone で Scriptable を開き、右上の **「＋」** を押します。
3. 空のスクリプト画面に、**貼り付け**ます。
   - Mac と iPhone が同じ Apple ID なら、Mac でコピーしたものを、そのまま iPhone に貼り付けられます（ユニバーサルクリップボード）。
   - うまくいかないときは、メモアプリや AirDrop で、テキストを iPhone に送ってください。
4. 画面上部の名前（「Untitled Script」など）を押して、**「お天気」** に変えます。
5. 右下の **▶（再生）** を押します。「どのウィジェットを見ますか？」と出るので、**「ロック画面（長方形）」** を選びます。天気が表示されれば成功です。

### 3. ロック画面に置く
1. iPhone のロック画面を、**長押し**します（Face ID などで解除が必要です）。
2. **「カスタマイズ」** → **「ロック画面」** を選びます。
3. 時計の下の枠（または、時計の上の日付）を押して、**「ウィジェットを追加」** を開きます。
4. **「Scriptable」** を選び、置きたい形（丸型・長方形・1行）を追加します。
5. 追加したウィジェットを押して、**「Script」** を **「お天気」** にします。
6. 右上の **「完了」** を押します。

### 4. 場所を変える（郵便番号）
ウィジェットの設定画面（手順3の5）で、**「Parameter」** に **郵便番号（7けた）** を入れます。例: `1600023`

- ハイフンなしで入れます。ハイフンや全角でも、読み取れます。
- 何も入れないと、スクリプトの `DEFAULT_LOCATION`（初期は新宿）の天気になります。
- ウィジェットは幅が狭いため、場所の名前は短く表示します（町名があれば町名、なければ市区町村。長いときは「…」で切ります）。
- 一度調べた郵便番号は、iPhone の中に保存され、次回から通信が1回減ります。
- 郵便番号が見つからないときは、初期の場所になります。

初期の場所を変えたいときは、スクリプトの先頭の `DEFAULT_LOCATION` の `name`・`lat`（緯度）・`lon`（経度）を書き換えます。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「天気を取得できません」と出る | 通信が不安定なときに出ます。10分ほどで、自動でもう一度試します。 |
| ウィジェットの内容が、なかなか変わらない | ウィジェットの更新は、iPhone が決めます。数十分おきになることが多く、リアルタイムではありません。 |
| 丸型のプレビューが出ない（「このバージョンの Scriptable では…」） | Scriptable が古いバージョンです。アプリを更新してください。ロック画面に置けば、動きます。 |
| 場所がおかしい | 郵便番号の位置は、住所から調べています。町名まで調べられないときは、市区町村の位置になります。 |
| 郵便番号の入力が反映されない | ウィジェットを一度削除して、追加し直してください。 |

## 使っているサービスと注意点

- 天気データ: [Open-Meteo](https://open-meteo.com/)（CC BY 4.0）
- 郵便番号 → 住所: [zipcloud](https://zipcloud.ibsnet.co.jp/)。予告なく止まることがあります。
- 住所 → 緯度・経度: 国土地理院の住所検索
- 入れた郵便番号と、調べた場所は、あなたの iPhone と、これらのサービスにだけ送られます。このリポジトリには送られません。
- 「降水確率」は、**今日1日の最大値**です。「傘 15〜18時」は、**いまから先**の時間の、降水確率が50%以上の時間帯です。

## 開発者向け（仕組み）

- Scriptable の `ListWidget` を使っています。ロック画面用の `accessoryCircular` / `accessoryRectangular` / `accessoryInline` と、ホーム画面用の `small` / `medium` に対応しています。
- 天気アイコンは、iOS 標準の SF Symbols です。夜（日の入りから日の出まで。時刻は天気データから取得）は、月の絵に変わります。時刻が取れないときだけ、19〜5時を夜とします。
- Scriptable の外では動きません。確認するときは、Scriptable の部品を代用品にして、Node で動かしました（通信は本物）。
